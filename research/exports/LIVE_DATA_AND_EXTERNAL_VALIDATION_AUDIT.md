# AegisOps Live-Data and External-Validation Audit

**Audit date:** 2026-10-15  
**Method:** Read-only repository, SQLite, CSV/JSON, model-metadata, and prior-audit inspection. No code, weights, thresholds, datasets, manuscript results, experiments, or external services were changed or executed. Credentials were not read or reproduced.

## Verdict

**C. Additional data or labels are required.** Existing local data supports an **operational pipeline demonstration only**. It cannot complete independently labeled detection-performance evaluation or external validation of the frozen LSTM. The independent AnoMod archive is locally present and provenance-verified, but its nominal data has no valid finite contiguous 24-step window for the frozen model. The earlier eight-step AnoMod path is off-contract and its target-calibration path has leakage and a numerical scale defect. [Evidence: `models/lstm_autoencoder.json:1-38`; `research/exports/telemetry.csv`; `research/exports/incident_episodes.csv`; `research/audits/EXPERIMENT_D_ZERO_SHOT_CONTRACT_AUDIT.md:121-154`; `research/audits/EXPERIMENT_D_CALIBRATION_INDEPENDENCE_AUDIT.md:18-81`]

## 1. Live-detection entry point and data flow

`app.py` imports and calls `render_live_monitoring()`, so the Streamlit view in `live_monitoring.py` is the actual live-detection entry point. [Evidence: `app.py:3,20`; `live_monitoring.py:606-615`]

1. **Ingress.** On the five-second Streamlit fragment cadence when collection is enabled, or on the manual control, `collect_live_sample()` reads collector-host CPU, memory, and disk via `psutil`; probes the configured target's `/probe`; measures elapsed HTTP time; records status/availability; and obtains the local demo service's `fault_mode` where available. It derives `error_rate_pct` from the current response plus the preceding 19 probe statuses. CPU, memory, and disk describe the collector host; latency/status/error rate describe the target. [Evidence: `live_monitoring.py:639-691`; `collectors/system_metrics.py:61-121`]
2. **Feature representation.** Each sample is inserted into `data/aegisops_live.sqlite3`, table `telemetry_samples`. Feature order is exactly `(cpu_pct, memory_pct, latency_ms, error_rate_pct, disk_pct)`, with units `%, %, ms, %, %`. [Evidence: `storage/telemetry_store.py:31-93`; `dl/anomaly_detector.py:13-16`]
3. **Window and score.** Only when separate file `models/live_lstm_autoencoder.pt` exists and at least 24 rows exist, the last 24 rows in insertion order are cast to `float32` and passed to `detect()`. It requires a finite `24 x 5` input, z-scores using checkpoint mean/std, reconstructs with the LSTM, takes MSE across time and features, then tests `score > threshold`. The live path does not check timestamp continuity before windowing. [Evidence: `live_monitoring.py:141-227`; `dl/anomaly_detector.py:151-183`]
4. **Alerts.** If no live checkpoint is present, rules flag CPU >=90%, memory >=95%, latency >=1000 ms, disk >=95%, a non-200 HTTP result, or a nonzero rolling error rate. In model mode these guards are ORed with the LSTM flag. Alert state transitions write `live_anomaly_detected` and `live_anomaly_recovered` into `incident_events`; the agent workflow is downstream and is not a source of labels. [Evidence: `live_monitoring.py:75-137,165-225,712-762`; `storage/telemetry_store.py:116-143`]

**Observed mode.** `models/live_lstm_autoencoder.pt` and its metadata are absent. All 200 telemetry rows have `detector_mode=bootstrap_rules`, and `anomaly_score` is null in 200/200 rows. The stored session evidences collection, rule fallback, alerts, and logging—not live LSTM inference. [Evidence: repository existence check of `models/live_lstm_autoencoder.pt` and `.json`; `data/aegisops_live.sqlite3`; `research/exports/telemetry.csv`]

## 3. Training, calibration, evaluation use, and leakage

The frozen model has 850 synthetic training windows, 150 held-out synthetic validation windows, a 24-step sequence, the stated feature order, synthetic scaler mean/std, and threshold `0.7093990445137024` (99th percentile of held-out normal reconstruction error). Local live data was not used for frozen-model training, scaler fitting, or threshold selection. [Evidence: `models/lstm_autoencoder.json:1-38`; `dl/anomaly_detector.py:192-239`]

An optional, separate live-training path would select successful HTTP-200, zero-error, `fault_mode='normal'`, non-breaching rows; split them chronologically 80/20; fit a new scaler/threshold; and write `models/live_lstm_autoencoder.pt`. It has not run: only eight current rows qualify versus the 180-sample minimum, and its artifacts are absent. Future use would be a retrained/calibrated live-model study, not frozen-model validation. [Evidence: `storage/telemetry_store.py:101-114`; `dl/live_training.py:19-97`; `live_monitoring.py:861-905`; `research/exports/telemetry.csv`]

Leakage/overlap risks:

- `fault_mode` is exposed by the local test service and also controls optional healthy-data selection. [Evidence: `collectors/system_metrics.py:96-121`; `storage/telemetry_store.py:101-114`]
- The 168 HTTP-500 records are one unrecovered injected episode, not independent events; hypothetical sliding windows would overlap, and the observed time series has long gaps. [Evidence: `research/exports/incident_episodes.csv`; `live_monitoring.py:147-160`; `research/exports/telemetry.csv`]
- Episode labels arise in the same workflow that produced rule alerts, rather than independent blinded adjudication. [Evidence: `research/exports/incident_episodes.csv`; `live_monitoring.py:712-762`]
- Historical 320-row predictions are evaluation outputs, but simulation-generated with injected labels and thus are non-independent synthetic benchmark evidence. [Evidence: `research/experiments/run_experiment_a.py:41-143`; `research/audits/AEGISOPS_MASTER_RESEARCH_HANDOFF.md:74-76`]

## 5. AnoMod ingestion and reconstruction-error scale

The extractor maps the three system-metric CSVs, rounds to a 15-s grid, derives latency P95 from `duration_us / 1000`, and derives 5xx percentage from traces. Strict mode rejects missing trace latency; preservation mode retains gaps for continuity-aware windowing. [Evidence: `research/experiments/run_experiment_d.py:139-222`]

The 23 trace-empty normal-baseline intervals leave only contiguous finite runs of 11, 11, and 18 observations. Because the frozen detector requires 24 finite steps, zero valid 24-step nominal windows result. TrainTicket's normal case has only 15 active intervals. This is a parser/data temporal-compatibility failure **before model scoring**, not a genuine model-generalization result. [Evidence: `dl/anomaly_detector.py:151-157`; `research/audits/EXPERIMENT_D_ZERO_SHOT_CONTRACT_AUDIT.md:121-154`; `research/audits/EXPERIMENT_D_SEQUENCE_COMPATIBILITY_DECISION.md:74-100`]

The prior harness hardcodes eight-step windows and directly calls `detector.model`, bypassing `detect()`'s 24-step assertion. Equal physical duration at 15 s does not preserve LSTM step semantics: a prior controlled check reports 0.339067 at eight steps versus 0.239059 at 24 (+41.8%). Eight-step values are off-contract diagnostics, not frozen-model threshold results. [Evidence: `research/experiments/run_experiment_d.py:579-596`; `research/audits/EXPERIMENT_D_SEQUENCE_COMPATIBILITY_DECISION.md:40-100`; `models/lstm_autoencoder.json:1-38`]

The target-calibrated branch has two distinct defects:

1. It fits a domain scaler on five eight-step calibration windows, uses the same eight validation windows to calibrate a 99th-percentile threshold, then evaluates those same windows as negatives. With strict `>`, no calibration score can exceed its own interpolated threshold: circular calibration/evaluation leakage, not a false-positive result. [Evidence: `research/experiments/run_experiment_d.py:537-550,565-639`; `research/audits/EXPERIMENT_D_CALIBRATION_INDEPENDENCE_AUDIT.md:18-81`]
2. The tiny calibration sample has near-zero reported std: zero `error_rate_pct` (epsilon-clipped to `1e-6`), 0.00064% disk, and 0.0188% memory. A one-percentage-point error rate can become approximately one million standard deviations and lead to loss around `10^12`. This is variance-collapse preprocessing/numerical behavior, not a frozen-model reconstruction-error measurement. [Evidence: `research/audits/EXPERIMENT_D_CALIBRATION_INDEPENDENCE_AUDIT.md:85-103`]

The separate frozen-scaler eight-step observation (mean nominal error reported as 59.19 versus frozen threshold 0.709399) may warn of domain shift, but it is confounded by off-contract window length and missing compatible normal data. It cannot establish a valid external false-alarm or generalization result. [Evidence: `research/audits/EXPERIMENT_D_SEQUENCE_COMPATIBILITY_DECISION.md:40-100`; `research/audits/EXPERIMENT_D_FINAL_SUPERVISOR_DECISION.md:16-30`; `models/lstm_autoencoder.json:1-38`]

## 6. Smallest scientifically defensible next step

Retain the local record only as an operational demonstration of collection, bootstrap alerting, local fault response, and incident logging. Do not calculate accuracy, sensitivity, specificity, false-positive rate, alarms/hour, or LSTM generalization from the 200 local rows. [Evidence: `research/exports/telemetry.csv`; `research/exports/incident_episodes.csv`; `research/paper/AEGISOPS_RESEARCH_PAPER.md:582,645,804-809`]

For **frozen-model external validation**, what is missing is an independently managed, provenance-recorded cohort with independently adjudicated normal/fault interval labels; all five features in the frozen order/units; finite contiguous 24-step windows at documented compatible cadence; enough disjoint normal windows for held-out false-alarm estimation; and a prespecified partition separating any target fitting/calibration from final evaluation. This is a proposal only: it does not authorize calibration, retraining, imputation, feature adaptation, or threshold change. [Evidence: `dl/anomaly_detector.py:13-16,151-183`; `research/audits/EXPERIMENT_D_CALIBRATION_INDEPENDENCE_AUDIT.md:145-164`; `research/audits/EXPERIMENT_D_FINAL_SUPERVISOR_DECISION.md:38-57`]

If a supervisor elects to use current AnoMod material, the distinct minimal proposal is a formally amended, explicitly exploratory eight-step, threshold-free ranking study. It must be described as off-contract, must not validate the frozen 24-step detector, and must resolve calibration leakage/variance collapse before execution. It is not silently adopted here. [Evidence: `research/audits/EXPERIMENT_D_SEQUENCE_COMPATIBILITY_DECISION.md:95-134`; `research/audits/EXPERIMENT_D_FINAL_SUPERVISOR_DECISION.md:38-74`]
