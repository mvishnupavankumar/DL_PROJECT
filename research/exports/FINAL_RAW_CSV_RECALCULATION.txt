3. EXPERIMENT A — RAW DETECTION RECALCULATION
======================================================================
Label encoding and valid cohort: ground_truth is binary (0 = normal, 1 = fault/anomaly). There are 200 normal rows and 120 fault rows; all 320 rows have valid labels and flags. No records were excluded.

For a method flag yhat and fault label y, the calculations are:
  TP = count(y=1,yhat=1); FP = count(y=0,yhat=1)
  TN = count(y=0,yhat=0); FN = count(y=1,yhat=0)
  precision = TP/(TP+FP); recall = TP/(TP+FN)
  specificity = TN/(TN+FP); F1 = 2TP/(2TP+FP+FN)
  FPR = FP/(FP+TN) = FP/200.

Recomputed flag metrics (N=320):
  Operational Rules [rule_flag]: TP 120, FP 0, TN 200, FN 0; precision 1.000000; recall 1.000000; specificity 1.000000; F1 1.000000; FPR 0.000000.
  Isolation Forest [iso_flag]: TP 57, FP 4, TN 196, FN 63; precision 0.934426; recall 0.475000; specificity 0.980000; F1 0.629834; FPR 0.020000.
  LSTM Autoencoder [lstm_flag]: TP 120, FP 2, TN 198, FN 0; precision 0.983607; recall 1.000000; specificity 0.990000; F1 0.991736; FPR 0.010000.
  Combined Alert [combined_flag]: TP 120, FP 2, TN 198, FN 0; precision 0.983607; recall 1.000000; specificity 0.990000; F1 0.991736; FPR 0.010000.

These flag-derived values agree with detection_metrics.csv (subject to its four-decimal rounding). The raw table contains only the single full Operational Rules flag. It does NOT contain narrow-rule or resource-only-rule flags, nor the underlying feature values needed to recreate them. Those separate-rule claims cannot be independently recalculated from this CSV and are therefore UNVERIFIED in this gate.

Ranking metrics and documented pipeline method:
  run_experiment_a.py calls sklearn.metrics.precision_recall_curve(y_true, score), then sklearn.metrics.auc(recall, precision). Higher score means more anomalous for both supplied continuous scores.
  Isolation Forest score column: iso_score = -decision_function; range in raw table [-0.1421522599, 0.0506389673]. Pipeline trapezoidal PR-AUC = 0.9055643731 (0.9056 rounded); sklearn average precision = 0.9060267404. These are different summaries and are not interchangeable.
  LSTM score column: lstm_score = reconstruction error; range [0.3083459139, 25243.87890625]. Pipeline trapezoidal PR-AUC = 1.0000000000; sklearn average precision = 1.0000000000.
  Rule score column: rule_score is binary 0/1. The historic runner nevertheless calculates trapezoidal PR-AUC = 1.0000000000 and average precision = 1.0000000000. The current manuscript's policy of marking a binary-rule ranking metric UNAVAILABLE is defensible, but it differs from the runner and detection_metrics.csv, which report 1.0.
  Combined alert has no score column in the runner and is N/A for PR-AUC.
