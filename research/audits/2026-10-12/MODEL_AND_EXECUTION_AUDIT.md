## 4. Dual Execution Modes in Multi-Agent Pipeline

`agents.IncidentAgents()` supports two distinct, non-overlapping execution modes:
1. **Live LLM Mode**: Activated when `GROQ_API_KEY` is set. Queries Groq Cloud using model `openai/gpt-oss-20b` with `temperature = 0.1` and `response_format = {"type": "json_object"}`.
2. **Deterministic Offline Mode**: Activated when `GROQ_API_KEY` is absent or upon network timeout. Uses regex pattern matching (`_local_root_cause()`) to produce structured JSON responses with zero latency and zero API cost.

> [!IMPORTANT]
> **Reporting Rule**: Research reports must **never pool** results from Live LLM Mode and Offline Deterministic Mode into a single benchmark. They must be evaluated and reported in separate rows.
